# ADR-002: 제목 표시줄은 화면이 그리고, 창 버튼 세 개만 창 쪽에서 그린다

- 일자: 2026-11-15
- 상태: Accepted
- 관련 명세: SPEC-20261115-app-skeleton (R10, AC1, AC15~AC18)

## Context
제목 표시줄을 기린 테마로 직접 그리되, 창을 다루는 동작(끌기, 더블클릭 최대화, 가장자리 크기 조절, 화면 끝에 붙이기, Windows 11 창 배치 메뉴)은 기본 창과 같아야 한다. 창 배치 메뉴는 Windows가 "마우스가 최대화 버튼 위에 있다"는 답을 창에서 직접 받아야만 뜬다. 화면(WebView2)이 그린 버튼은 그 답을 줄 수 없다.

## Decision
- 창 틀 계산(`WM_NCCALCSIZE`)에서 위쪽 제목 표시줄만 없애고 좌우·아래 틀은 남긴다.
- 프로젝트 탭 줄을 포함한 제목 표시줄은 화면이 그린다. 빈 곳은 CSS `app-region: drag`로 표시하고, WebView2의 비클라이언트 영역 지원을 켜서 끌기·더블클릭·붙이기를 Windows 기본 동작에 맡긴다.
- 최소화·최대화·닫기 버튼은 화면 위에 얹은 작은 창(`VisualAgentCaption`)이 색상표의 색으로 그린다. 이 작은 창이 마우스 위치를 묻는 질문에 직접 `HTMINBUTTON`·`HTMAXBUTTON`·`HTCLOSE`로 답하고, 누름·뗌도 직접 처리한다.
- 창 맨 위 4px 띠는 화면으로 덮지 않고 위쪽 크기 조절 영역으로 쓴다. 최대화 상태에서는 띠를 없앤다.
- 화면은 창 버튼 폭(`window.__VA__.captionWidth`)만큼 제목 표시줄 오른쪽을 비워 둔다.

## Alternatives Considered
| 대안 | 장점 | 단점 | 기각 사유 |
|---|---|---|---|
| 창 버튼도 화면(HTML)이 그림 | 코드가 한곳에 모임 | 창 배치 메뉴가 뜨지 않음 | AC18 미충족 |
| 창 버튼 영역이 입력을 아래 창으로 넘기고(`HTTRANSPARENT`) 앱 창이 답함 | 앱 창 한 곳에서 처리 | 넘긴 입력을 앱 창이 아니라 다른 프로세스가 그리는 화면(WebView2)이 가져감. 버튼이 눌리지 않고 창이 끌림 | 처음에 이 방식으로 만들었다가 실제 클릭에서 동작하지 않아 폐기 (2026-11-15) |
| 화면이 mousedown을 알리고 창이 끌기를 흉내 냄 | 예전 WebView2에서도 동작 | 더블클릭·우클릭 메뉴를 따로 구현해야 함 | 기본 동작과 어긋날 여지가 큼 |
| 화면 부품을 합성 방식으로 띄우고 모든 마우스 입력을 창이 전달 | 입력을 완전히 통제 | 코드량과 위험이 큼 | 뼈대 범위를 넘음 |

## Consequences
- 창 버튼의 색과 눌림 표시는 C++ 코드(`core/src/app/app_window.cpp`)에 있다. 색은 빌드 때 색상표에서 만든 상수만 쓴다.
- 창 버튼 그림은 Windows 글꼴 "Segoe MDL2 Assets"에 의존한다.
- 원격 기기(브라우저)에는 창 버튼이 없으므로 화면은 `captionWidth`가 없으면 0으로 본다.

## Enforcement
- 가장자리·모서리·창 버튼 자리의 판정값: `ui/e2e/app.e2e.mjs` ("AC17 …")
- 창 버튼 영역이 입력을 아래로 넘기지 않고 버튼 종류로 답하는지: `ui/e2e/app.e2e.mjs` ("AC17 …")
- 최대화 시 화면 영역 일치, 최소화, 닫기 (신호 전달): `ui/e2e/app.e2e.mjs` ("AC16 …")
- 창 버튼을 실제 마우스로 클릭: `ui/e2e/caption.e2e.mjs` (품질 게이트 밖, `npm run e2e:mouse`)
- 실제 마우스로 끌기·더블클릭·크기 조절·붙이기: `ui/e2e/mouse.e2e.mjs` (커서를 움직이므로 품질 게이트 밖, `npm run e2e:mouse`)
- 창 쪽 코드의 색 값 직접 사용 금지: `ui/scripts/lint-colors.mjs`
- 창 배치 메뉴가 실제로 뜨는지는 자동 검사 없음, 사유: 마우스를 올려 두었을 때 Windows가 그리는 메뉴라 프로그램으로 확인할 방법이 없음
