## 품질 게이트
모든 변경이 통과해야 하는 단일 명령.

```
(미정. SPEC-20261115-app-skeleton 구현 시 확정)
```

베이스라인 파일: 없음

## 실행·증적 수집 명령

| 용도 | 명령 |
|---|---|
| 앱 실행 | (미정) |
| E2E 테스트 | (미정) |

## 패스트트랙
명세 없이 구현 가능한 조건 (전부 충족 필요):
- 변경 범위가 작고 되돌리기 쉬움
- 가정 사항 발생 여지 없음 (오타, 문구, 명확한 단일 수정)
- 결제, 개인정보, 권한, 상태 전이, 영속 데이터와 무관
- DB 스키마·데이터 마이그레이션 아님

**항상 정식 절차**를 적용하는 영역:
- SNS 게시, 댓글 답변, 좋아요 등 외부 계정에 반영되는 모든 동작
- 자격 증명(토큰, 접속 코드) 처리
- 아이폰 등 다른 기기에서의 접속 경로
